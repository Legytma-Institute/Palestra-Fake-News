“Bastam 3 segundos de áudio para clonar uma voz”

Fato

Por que é fato: num teste de laboratório, 3 segundos de áudio geraram um clone com 85% de semelhança com a voz original.

Fonte: McAfee Labs, 2023 (relatório de empresa, não revisado por pares)

Este é o caso verdadeiro que parece falso. Ele está aqui para ninguém sair achando que "tudo é mentira". O dado vem de um teste do McAfee Labs de 2023: é relatório de empresa, não estudo revisado por pares, então diga isso com honestidade. Mas o risco é real: golpistas usam áudios publicados nas redes para clonar a voz de alguém e pedir Pix para a família. Vamos voltar a isso no bloco de IA.
